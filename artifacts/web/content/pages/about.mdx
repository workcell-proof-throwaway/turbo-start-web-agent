## Content is MDX in git

Pages live under `content/`. Each page is data, not code: you assemble Blocks
and pass them literal values. There is no CMS and no database.

## The build is the gate

Bad frontmatter or bad Block props fail the build by design. If the build
passes, the content is valid.
